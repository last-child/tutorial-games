# 팍스런 (fox)

가로 무한러너. 2026-10-21에 화면부터 만들기 시작했다. 사용자 말: "유령게임 구조처럼 하되. 일본풍 게임을 하자." 제목은 "팍스런"이다(처음 임시 제목은 "신사 여우". 2026-10-21 사용자가 캐주얼 게임 이름을 정했다: "수달 쓰다듬기, 고스트점핑, 팍스런".). 폴더 이름은 `fox`. 지금은 화면, HUD, 흐르는 배경, 달리는 여우, 시작/일시정지, 점프, 배경음, 다루마(방해물), 하트 잃기, 게임 오버와 다시하기까지 된다.

- **그림은 사용자가 준 것을 그대로 쓴다.** 사용자가 넣어 준 것을 이 폴더로 옮겼다.
  - 배경: 원본 `img/신사.png`(2172×724, 밤 신사 파노라마). 페이지는 `img/shrine.webp`(같은 크기)를 쓴다.
  - 여우 달리기: `img/fox-run-assets.zip`(사용자가 준 압축 파일 그대로)에서 꺼낸 `img/run/fox-run-01~06.png`(투명 배경 512×512, 초당 10장 권장)를 3열 × 2행 시트 `img/fox-run.webp`로 묶어 쓴다. 압축 파일 안의 `shrine-background.png`는 파일이 잘려 있어서 쓰지 않는다.
  - 여우 점프: `img/fox-jump-assets.zip`(사용자가 준 압축 파일 그대로)에서 꺼낸 `img/jump/fox-jump-01~06.png`(투명 배경 544×544, 웅크리기 → 도약 → 상승 → 정점 → 하강 → 착지)를 3열 × 2행 시트 `img/fox-jump.webp`로 묶어 쓴다. 달리기 그림과 같은 축척이다. 처음 뛸 때 깜빡 사라지지 않게 페이지를 열 때 미리 불러 둔다.
  - 다루마: `img/daruma-left-wobble-assets.zip`(사용자가 준 압축 파일 그대로)에서 꺼낸 `img/daruma/daruma-left-wobble-01~08.png`(투명 배경 360×360, 왼쪽을 보고 흔들거림, 초당 5장, 기준점 (180, 330))를 4열 × 2행 시트 `img/daruma.webp`로 묶어 쓴다. `img/daruma/daruma-left.png`(1254×1254 한 장)는 원본으로만 둔다.
  - `img/여우.png`(1536×1024, 뛰어오르는 자세 한 장)는 처음 받은 그림이다. 달리기 그림으로 바꾼 뒤로는 페이지에서 쓰지 않는다.
  - 여우를 SVG로 다시 그려 보다가 원본보다 많이 단순해져서 그만뒀다. 다리를 따로 움직이려면 SVG가 필요하다는 것, 아니면 달리는 자세 그림을 몇 장 더 받아야 한다는 것을 사용자에게 말해 두었다.
  - 신사 그림은 오른쪽 끝과 왼쪽 끝이 이어지게 그려져 있어서 그대로 옆으로 반복한다.
- **홈페이지 카드 (2026-10-21 사용자 요청: "fox도 홈페이지에 집어넣어볼래? 썸네일도 넣고"):** 메인 홈페이지(루트 `index.html`) 캐주얼 게임 섹션의 다섯 번째 카드다. 표지(`.cover.fox`)는 `img/cover.webp`(800×500)로, 사용자가 준 그림만으로 합성했다: `img/신사.png`를 1.45배 당겨 도리이와 벚꽃이 보이게 자르고(돌길이 표지 높이 74%), 그 위에 다루마(`daruma-left-wobble-01.png`)와 그 위를 뛰어넘는 여우(`fox-jump-03.png`, 상승 그림)를 얹었다. 처음엔 여우가 작아 눈에 덜 띄어서 키웠고, 귀가 잘리지 않게 높이를 맞췄다.
- **가로 화면 (2026-10-21 사용자 결정: "가로로 하자. 모바일도 가로로 할거야"):** 틀은 16:9~2.2:1이다. 그보다 좁은 창은 위아래를, 넓은 창은 양옆을 남색으로 비운다(`Fox.frame`). 손가락으로 쓰는 기기를 세로로 들면 "가로로 돌려 주세요" 안내(돌아가는 폰 그림)가 덮는다. 폰에서 처음 시작 버튼을 누르면 전체 화면과 가로 고정을 시도한다. 안 되는 브라우저는 그냥 넘어간다.
  - 1em은 틀 높이의 1%다(`#stage`의 `--unit`). HUD 크기는 모두 em이다. 버튼은 글자 크기를 물려받지 않으므로 `#start`에 `font-size: inherit`이 꼭 있어야 한다.
- **배경:** 그림을 틀 높이에 맞춰 깐다. 돌길 뒤쪽 끝(그림 높이 73.5%)에서 두 겹으로 나눴다. 위 풍경은 돌길의 0.35배로 느리게, 돌길과 돌담은 초당 틀 높이 0.62만큼 흐른다(`Fox.SCROLL`). 여우 발은 그림 높이 75.7%에 닿는다(`Fox.ART`).
- **여우 (2026-10-21 사용자 요청: "시작 화면을 누르면 이 녀석이 달리는 것만 해도 좋아"):** 달리기 그림 한 칸을 틀 높이 30% 크기로 왼쪽 5% 자리에 그린다(`Fox.HERO`). 그림 높이 92.4%(가장 낮은 발끝)를 돌길에 맞춘다. 시작 전에는 1번 그림으로 서 있고, 시작하면 달린 시간에 따라 초당 10장으로 6장을 돌린다. 일시정지하면 그 그림에서 멈춘다. 발밑 그림자는 높이 뜰수록 작고 옅어진다.
- **점프 (2026-10-21 사용자 요청: "스페이스나 클릭을 하면 점프동작이 되게", 점프 그림을 줌):** 스페이스, 화면 톡, 마우스 클릭(버튼 제외). 누르면 0.06초 웅크렸다가(`Fox.POSE.crouch`) 솟구친다. 꼭대기는 틀 높이의 0.34배, 꼭대기까지 0.4초. 유령 게임과 같은 방식으로 1/240초씩 나눠 계산한다. 시작 전, 일시정지 중, 공중, 웅크리는 중에는 뛰지 않는다.
  - 그림 고르기(`Fox.pose`): 웅크리기 → 공중에서는 오르는 빠르기로 도약(처음 빠르기의 55% 넘게) → 상승(20% 넘게) → 정점(-25%까지) → 하강 → 착지하면 착지 그림 0.12초 → 다시 달리기.
  - 그림 놓기: 점프 그림마다 여우가 칸 안 다른 높이에 그려져 있어서, 그림마다 방울 자리와 가장 낮은 점을 재 두었다(`Fox.JUMP_ART`). 웅크리기와 착지는 가장 낮은 점(발끝)을 돌길에 붙인다. 공중 그림은 방울을 "달릴 때 방울 높이(달리기 그림 땅 줄 위 124px) + 점프 높이"에 맞추고, 가장 낮은 점이 땅 밑으로 가지 않게 막는다. 가로는 방울을 달리기 그림의 방울 자리(420px)에 맞춘다.
- **다루마 (2026-10-21 사용자 요청: "여우의 반 크기", "부딪히면 하트 하나 줄어들고 다 떨어지면 게임이 바로 끝나게"):** 돌길에 놓인 채 흔들거리며 돌길과 같은 빠르기로 흘러온다(`Fox.DARUMA`). 크기는 여우 키(귀 끝~발끝, 틀 높이의 약 0.217배)의 반이라 그림 칸이 틀 높이의 0.176배다. 다루마마다 흔들리는 박자를 어긋나게 한다(`phase`). 첫 다루마는 시작 2초 뒤, 그다음은 1.5~3.3초 간격(한 번 뛰어 착지하고 숨 돌릴 틈).
  - 판정(`Fox.heroBox`, `Fox.darumaBox`): 여우는 달리기 그림 칸 안 꼬리와 귀를 뺀 몸통·머리(가로 240~475px, 발에서 위로 230px)에 점프 높이를 더한 네모, 다루마는 몸통 너비의 80%·높이의 90% 네모. 알맞게 뛰면 넉넉히 넘는다(Node 자동 플레이 60초 동안 0번 부딪힘).
  - 부딪히면 하트가 하나 줄고, 그 다루마는 다시 판정하지 않으며, 여우가 1.2초 깜빡이며 다치지 않는다(`HURT_SAFE`). 잃은 하트는 톡 커졌다가 빈다. 콩 소리(속 빈 종이 다루마)와 고토가 반음 내려앉는 소리, 폰은 0.16초 진동.
  - 하트가 다 떨어지면 그 자리에서 바로 게임 오버다. 음악이 줄고 더 큰 콩과 북, 고토가 아래로 흘러내리는 소리, 폰은 0.32초씩 세 번 진동(2026-10-21 사용자: "모바일에서 부딪힐 때 진동효과도", 유령 게임과 같은 세기). 여우와 다루마는 그 자리에 멈추고 시작 버튼은 숨는다. 0.6초 뒤 가운데에 남색 옻칠 카드(금빛 테)가 뜬다: "게임 오버", 점수, 주홍 "다시하기" 버튼. 스페이스도 다시하기다.
  - 다시하기(`Fox.restart`): 하트 4개, 점수 0, 다루마 없음으로 곧바로 달린다. 배경은 멈춘 자리에서 이어 흐르고 음악은 처음부터.
  - 여우가 부딪히는 그림은 사용자가 나중에 준다고 했다. 그때까지는 깜빡임만 한다.
- **HUD (2026-10-21 사용자가 정함):**
  - 왼쪽 위 하트 4개(진홍 `#e8434f`, 짙은 테두리). 잃은 하트는 남색으로 빈다(`.is-empty`). 하트 그림은 `<use>`로 불러 써서 안쪽에 CSS 선택자가 닿지 않으므로 색은 `--heart-fill`, `--heart-shine` 변수로 넘긴다.
  - 하트 아래 코인: 별이 박힌 금빛 동전 그림과 "× 개수"(Jua, 흰 글자에 남색 테두리). 위치는 내가 제안하고 사용자가 받았다. 코인은 판 안에서 줍는 아이템이고 저장하지 않는다. 줍는 규칙은 아직 없다.
  - 가운데 위 흰 둥근 상자에 "SCORE"와 점수(Jua). 점수는 1초에 10점.
  - 오른쪽 위 주홍 옻칠 동그란 시작/일시정지 버튼(금빛 테, 글자 없는 ▶/Ⅱ 그림). 일시정지하면 장면이 조금 어두워진다.
- **진동:** 폰에서 화면이나 버튼을 톡 치면 12ms 약하게 떤다(유령 게임과 같음).
- **배경음 (2026-10-21 사용자 선택: 세 안 중 "〈오오카미〉 풍"):** Web Audio로 합성한다(`Music`). 유령 게임 배경음과 같은 구조다(버튼 누른 순간에 소리를 켜고, 일시정지하면 `suspend`로 그 자리에서 멈췄다 이어짐, 0.05초마다 0.3초 앞까지 예약).
  - 미야코부시 음계(라 시♭ 레 미 파), 128 BPM, 4/4박, 16마디 되풀이. 마디마다 바닥 음(`ROOT`)이 바뀌고 낮은 삼각파 울림이 따라간다.
  - 앞 8마디: 고토가 선율(`KOTO`), 3개 이상 긴 음은 줄을 눌러 반음 아래서 올린다. 곡이 처음 돌아올 때마다 고토를 아래서 위로 훑는다.
  - 뒤 8마디: 대나무 피리(시노부에, 한 옥타브 위, 숨소리와 늦게 들어오는 떨림, 위에서 꺾어 붙임)가 선율(`FLUTE`), 고토는 8분음표로 잘게 반주(`ARP`), 작은 징(카네)이 2·4박 사이에 들어간다.
  - 고토는 줄을 튕기는 원리(카플러스-스트롱)로 음마다 한 번 만들어 둔다. 타이코는 둥(낮게 떨어지는 북 울림)과 딱(테두리), 넷째 마디마다 둥둥으로 채운다.
  - 소리 크기: 오프라인으로 16마디를 렌더링해 쟀을 때 봉우리 0.88, 깨지는 샘플 없음. 압축기 뒤 출력 0.85가 그 값을 맞춘 것이라 악기를 더하면 다시 재야 한다.
  - 소리 켜기/끄기: 시작 버튼 왼쪽의 작은 남색 옻칠 버튼(같은 금빛 테). localStorage `hooni-fox-sound`(`off`면 끔).
  - 효과음은 음악과 따로 `sfx`로 낸다(게임 오버로 음악이 줄어도 들린다, 소리 끄기를 따른다). `Music.hurt`, `Music.over`, `Music.jump`.
  - 점프음(2026-10-21 사용자 요청: "충돌음이나 점프음"): 실제로 뛸 때만(웅크리기 시작) 휙 하는 바람(잡음을 600→2400Hz로 훑음)에 목에 단 방울(스즈)이 두 번 딸랑. 자주 나니까 봉우리 0.24로 작게 했다(충돌 0.79, 게임 오버 0.88). `Music.setPace`(빨라지기용)는 자리만 있고 아직 부르는 곳이 없다.
- 아직 정하지 않은 것: 코인이 나오는 방식, 빨라지기, 최고 기록.
