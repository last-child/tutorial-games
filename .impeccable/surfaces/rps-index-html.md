# 냥토 가위바위보 (rps/index.html)

Scope: 1인용 게임(홈페이지에서 링크하지 않음). Mode: Experience — 고양이와 토끼가 마주 선 무대가 첫 화면의 주인공.
Audience/job: 공유 링크로 온 친구가 폰이나 PC에서 3점 먼저 내기를 하고, "한 판 더!"를 누른다.
Constraints: file://로 열림, 단일 HTML + `img/` 폴더, 사용자가 준 PNG 에셋(`img/`)의 그림체를 따른다. 틀 바깥 여백은 hooni-hue 테마. 군더더기 문구 없음.
History:
- 2026-10-08 v1: TCG 손패 버전, 사용자가 "너무 이상하다"고 해서 버렸다.
- 2026-10-08 v2: 수달/너구리 SVG 연승 버전. 사용자가 PNG 에셋을 주면서 다시 만들게 했다.
- 2026-10-08 v3(현재): 고양이(나) vs 토끼(상대), 에셋 기반.
  - 말풍선은 꼬리 방향과 배치가 어색하다는 지적을 받아 모두 뺐다.
  - LOSE 배너의 토끼는 우는 고양이로 바꿨다.
  - 위쪽 요소는 튀지 않게 했다.
  - 풀숲과 버튼판은 화면 너비 전체로 넓혔다.

## Direction contract
THESIS: 미니게임천국처럼 아기자기한 무대다. 두 캐릭터가 풀숲 뒤에 서 있고, 나무 버튼판에 놓인 큰 손 버튼 세 개가 무대를 받친다.
OWN-WORLD: 배경은 에셋의 호숫가 그림이다. 캐릭터와 UI는 진한 갈색 외곽선(`--line #3b2314`)과 크림색(`#fff6e2`)으로 맞춘다. 나무판은 VS 배너의 나무색을 쓴다. 글씨는 Jua에 갈색 외곽선을 두른다.
STORY: 손 버튼을 누르면 "가위! 바위! 보!"가 세 박자로 커졌다 튄다. 그동안 두 캐릭터는 공격 포즈로 뛴다. 이어서 두 손 카드가 양옆에서 날아와 공개된다. 결과가 나오면 이긴 쪽은 승리 포즈로 세 번 점프하고 별 이펙트가 터지며, 진 쪽은 우는 포즈로 축 처진다. 그 위로 WIN/LOSE/DRAW 배너가 튀어나온다. 3점이 나면 결과 카드(점수, 한 판 더!)가 뜬다.
FIRST VIEWPORT: 맨 위에 홈, 소리 버튼을 둔다. 그 아래에 나/상대 점수판과 VS 배너를 놓는다. 가운데는 하늘 무대이고, 아래쪽 풀숲 뒤에 왼쪽 고양이와 오른쪽 토끼가 선다. 맨 아래 나무판에는 가위·바위·보 버튼을 둔다.
SIGNATURE: 통통 튀는 움직임이다. 캐릭터는 숨 쉬듯 눌렸다 늘어나고, 버튼은 둥실거리다 누르면 찌그러진다. 배너와 카드는 크게 튕기며 등장한다. 위쪽 요소(상단 바, 점수판, VS)는 움직이지 않는다.
SIZING: 1u = 게임판 너비의 1%이고, 화면 높이가 180u보다 낮으면 높이에 맞춰 줄어든다. 게임판 최대 너비는 480px이다.
FINISH: unreviewed and undocumented is unfinished.
