# 푸리나 새 에피소드 기획 지시

지금까지 조사한 푸리나 설정을 바탕으로 새 에피소드 방향을 잡자.

아직 대본은 쓰지 마.
먼저 10~15분짜리 웹 미연시용 스토리 시놉시스 3개만 제안해줘.

중요한 전제:
- 시점은 폰타인 아르콘 퀘스트 이후
- 푸리나는 현재 신 역할에서 벗어난 인간 푸리나
- 플레이어는 푸리나와 어느 정도 친분이 있는 인물
- 로맨스는 노골적이지 않고, 친근함과 미묘한 호감 정도
- 푸리나의 장난기, 허세, 연극적인 리액션은 살릴 것
- 하지만 법정/재판/판결/심리 같은 느비예트식 소재는 쓰지 말 것
- 포칼로스, 예언, 500년의 고통 같은 과거를 직접 고백하는 장면은 넣지 말 것
- 푸리나가 갑자기 자기 트라우마를 장황하게 설명하지 말 것
- 푸리나를 전형적인 츤데레로 만들지 말 것
- 푸리나의 허세는 이제 강제로 쓰는 가면이라기보다 오래된 습관과 본래의 쇼맨십처럼 표현
- 연극/배우/대사 연습/관객 반응 같은 요소를 활용해도 좋음
- 케이크나 디저트 소재는 적극적으로 활용해도 좋음
- 첫 버전의 '푸리나와 같이 케이크를 먹으면서 장난치는 분위기'는 마음에 들었음

스토리적으로 원하는 것:
- 단순히 케이크 먹고 호감도 선택지를 고르는 구조보다 작은 사건이나 목표가 하나 있었으면 함
- 선택 때문에 실제 대화나 상황이 달라지는 느낌이 있어야 함
- 성공/실패 엔딩보다는 관계 분위기가 달라지는 3개 정도의 엔딩이 좋음
- 억지 감동이나 무거운 트라우마 고백은 금지
- 일상적이고 귀엽고, 푸리나답게 재미있는 이야기가 우선

현재 사용 가능한 장소 에셋은 폰타인풍 살롱의 저녁/밤 배경이므로,
가능하면 대부분의 이야기가 한 장소에서도 성립하게 해줘.
필요하다면 이후 배경을 추가할 수 있으므로 다른 장소를 제안해도 괜찮지만,
왜 필요한지도 설명해줘.

각 시놉시스마다 아래만 적어줘:
1. 제목
2. 한 줄 premise
3. 시작 → 중반 사건 → 클라이맥스 → 마무리
4. 푸리나의 매력이 드러나는 포인트
5. 선택지로 갈라질 만한 지점 3~5개
6. 예상 엔딩 3종
7. 이 이야기가 푸리나에게 어울리는 이유

아직 실제 대사나 scenario.ts는 작성하지 마.
내가 시놉시스를 고른 다음에 대본을 작성할 거야.
