# Furina VN Prototype Pack

가벼운 웹 미연시 테스트용 패키지.

## 구성

```txt
furina/
├─ furina_script.md
├─ CLAUDE_CODE_PROMPT.md
├─ furina_audio/
│  ├─ bgm/
│  ├─ ambience/
│  └─ sfx/
├─ furina_bg/
│  ├─ bg_salon_day.png
│  ├─ bg_salon_evening.png
│  └─ bg_salon_night.png
└─ furina_sprite/
   ├─ furina_default.png
   ├─ furina_happy.png
   ├─ furina_pout.png
   ├─ furina_flustered.png
   ├─ furina_sad.png
   └─ furina_surprised.png
```

## Claude Code에 줄 것

가장 간단한 방법:
1. 이 폴더 전체를 작업 폴더에 넣는다.
2. `CLAUDE_CODE_PROMPT.md`의 내용을 Claude Code에 전달한다.
3. `furina_script.md`를 기준으로 구현하게 한다.

## 참고

- 오디오는 이 프로토타입용으로 새로 생성한 테스트 자산이다.
- 제공된 캐릭터/배경 이미지는 이번 팬 프로토타입 테스트용으로 정리한 자산이다.
- 보이스는 포함하지 않았다.
