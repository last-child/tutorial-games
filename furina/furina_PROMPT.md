# Claude Code 구현 지시문

이 폴더는 10분 내외 웹 미연시 프로토타입용 에셋 패키지다.

## 반드시 기준으로 삼을 파일
- `furina_script.md`

이 파일을 스토리와 연출의 **source of truth**로 사용한다.
대사, 선택지, 엔딩 조건을 임의로 다시 쓰거나 늘리지 않는다.

## 제공 에셋
- `furina_audio/`
- `furina_bg/`
- `furina_sprite/`

`furina_script.md`의 에셋 매핑과 파일명을 그대로 연결한다.

## 구현 목표
- 16:9 웹 미연시
- 클릭 또는 Space/Enter로 대사 진행
- 타이핑 효과
- 푸리나 표정 스프라이트 교체
- 배경 crossfade
- 선택지 3회
- affection 상태값에 따른 엔딩 2종
- BGM / ambience / SFX
- 첫 사용자 입력 이후에만 오디오 재생
- BGM 1.5초 crossfade
- 음소거 및 간단한 BGM/SFX 볼륨 조절
- 오디오나 이미지 파일 로드 실패는 non-fatal 처리
- 모바일도 깨지지는 않게 하되 PC 16:9를 우선

## 구현 방식
기존 프로젝트가 있으면 그 구조를 존중한다.
빈 폴더라면 가볍게 실행 가능한 웹 프론트엔드 구조로 만든다.
에셋은 브라우저에서 안정적으로 서빙되도록 적절히 public/static 경로에 배치해도 되지만,
원본 파일명은 바꾸지 않는다.

## 하지 말 것
- 대사 재작성
- 추가 캐릭터 생성
- 세이브/로드 시스템
- 복잡한 인벤토리/호감도 UI
- 원신 공식 음원/보이스 추가
- 불필요한 백엔드

완성 후 실행 방법과 주요 파일 구조만 짧게 설명한다.
